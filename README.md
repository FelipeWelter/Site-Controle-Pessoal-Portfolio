# Site de Controle Pessoal · Portfólio

Protótipo PHP/MySQL para cadastro de usuários e registro de entradas e saídas.

Crie um banco local, aplique `schema.sql` e configure `DB_HOST`, `DB_NAME`, `DB_USER` e `DB_PASSWORD` no ambiente. Inicie com `php -S 127.0.0.1:8000` e acesse `register.php` para criar a conta de teste. Use apenas dados fictícios na demonstração local.
